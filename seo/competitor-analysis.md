# AxomRank — Competitor Analysis & Market Gap Blueprint

## 1. Competitor Matrix

| Competitor | Primary Strengths | Major UX / Technical Weaknesses | AxomRank Strategic Advantage |
| :--- | :--- | :--- | :--- |
| **Lucent / Local Coaching** | Brand recognition in offline Assam coaching | Cluttered traditional UI, outdated PDF downloads, no performance analytics | Modern tech stack, mobile-first design, interactive PYQs, instant analytics |
| **GyanTest / Local Mocks** | Large quantity of mock tests | Generic UI, slow mobile performance, no adaptive mistake bank | Instant interactive feedback, Mistake Bank, Assam-first UI identity |
| **National Platforms (Testbook, Adda247)** | Massive scale & SEO domain authority | Generic national template, poor Assamese language nuance, non-tailored Assam GK | 100% Assam-focused content depth, local dialect accuracy, specialized Assam tools |
| **Sadhna AI** | AI study planning angle | Cluttered feature list, lack of deep organic hub architecture | Seamless SEO-to-Product loop, free interactive tools without login walls |

## 2. Identified Content & Opportunity Gaps
1. **Interactive PYQ Solving**: Competitors offer static PDFs. AxomRank provides an interactive online PYQ solver with detailed bilingual explanations.
2. **Dedicated Free Interactive Tools**: Zero competitors offer an instant ADRE Score Calculator or Eligibility Checker designed specifically for Assam reservation rules and grade categories.
3. **Mistake Bank Concept**: Competitors present test series as one-off attempts. AxomRank automatically archives wrong answers into a persistent "Mistake Bank".
4. **Assam GK Granularity**: Competitors group Assam GK into generic bullet lists. AxomRank structures Assam GK into interactive subject nodes and micro-quizzes.
